## Image and responsive rules

- Portfolio cards use an `8 / 5` aspect ratio at every breakpoint.
- Current standardized exports are `1600 × 1000` pixels.
- Use `object-fit: cover` and project-specific focal positions.
- Preserve full screenshots in each project's `originals` directory.
- Mobile cards retain the same ratio; project detail galleries may use taller screenshots.
- Never stretch screenshots or allow cards in the same grid to have different heights.
