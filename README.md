# Nobleman U. Portfolio

Responsive static portfolio for Nobleman U., focused on web development, software solutions, and AI automation.

## Preview

Run `npm run dev`, then open `http://localhost:4173`.

## Deploy

Deploy to Vercel and configure these environment variables:

- `RESEND_API_KEY`
- `CONTACT_TO_EMAIL`
- `CONTACT_FROM_EMAIL`

The contact form uses a Vercel function in `api/contact.js` and Resend for delivery.
